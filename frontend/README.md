# Фронтенд Ладов

Веб-интерфейс личной библиотеки Guitar Pro для занятий гитарой.
Основа — React, TypeScript и Gravity UI. Тексты вынесены в ключи локализации.

Код разделён на модули по предметным областям. Внутри модуля api содержит
запросы, model — состояние и правила, ui — компоненты. Страницы связывают модули.

Сейчас реализованы вход через Яндекс ID и Google, проверка сессии и выход.
Музыкальная библиотека и плеер будут добавляться отдельно.
